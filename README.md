# Cellar

An advanced native music player for YouTube Music, for macOS, Windows and iOS.

Cellar talks to YouTube Music directly with your own account, and adds the
things a serious listener wants: gapless and crossfaded transitions, offline
downloads, a real queue you can reorder, listening history that syncs across
your devices, playlist folders, and a desktop mini player.

## Releases
